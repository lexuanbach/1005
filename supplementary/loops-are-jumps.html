Loops Are Just JumpsSupplementary

There is no while instruction in your CPU. There is no for, and no do-while either. Every loop you wrote in Chapter 4 compiles down to exactly two abilities the hardware does have: compare two numbers and jump to a different instruction. The Jump Machine below lets you run your Chapter 4 loops the way the machine really does.

01 · The idea

Compare, then jump — that is the whole secret

S5.1How a while loop compiles

The compiler (S1) translates while (count <= 10) into a test-and-jump sandwich: a labelled test at the top, a conditional jump that leaves when the condition fails, the body, and an unconditional jump back up:

while (count <= 10) — as the machine sees it
      SET  count, 1
TEST: CMP  count, 10    ; while (count <= 10) …
      JGT  END          ; …really means: if count > 10, LEAVE
      PRINT count       ; the body
      ADD  count, 1
      JMP  TEST         ; the backwards jump IS the loop
END:  HALT

Notice the condition is inverted: the C++ says “continue while ≤ 10”, the machine says “leave if > 10”. And the loop itself is nothing but the JMP TEST — an arrow pointing backwards, exactly like the flowchart arrows of Chapter 1.

S5.2for and do-while are the same trick, rearranged

  • for(init; cond; update) compiles to: init above the label, the update just before the backwards jump — the same sandwich with the bookkeeping folded in.
  • do-while puts the test at the bottom: the body runs, then a single conditional jump goes back up if the condition still holds. One test per pass, and the body always runs once — the post-test behaviour of Chapter 4, explained by instruction order.

And break? It is simply a jump to END. continue? A jump to TEST (or to the update). Even if/else from Chapter 3 is the same machinery — a conditional jump over the branch not taken.

S5.3Infinite loops, seen from below

At machine level an unintentional infinite loop is nothing mysterious: the backwards jump is always taken because nothing between the label and the jump ever changes the compared register. Forgetting count++ in C++ is deleting the ADD count, 1 line here — try it in the Lab and watch the step counter run away.

Things to try Count how many instructions one pass of the while-loop costs (CMP, JGT, PRINT, ADD, JMP — five). Watch the do-while preset: where is its test, and why does the body always run once? Step the very last pass of each loop and observe the one time the conditional jump is finally taken.
