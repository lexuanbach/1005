Arrays in MemorySupplementary

a[i] looks like magic notation — it is actually one multiplication and one addition: base address + i × size. That single formula explains why indices start at 0, why 2-D arrays are secretly flat, and why writing one step past the end of an array silently destroys whatever lives next door.

01 · The idea

One formula explains everything

S6.1Indexing is address arithmetic

Chapter 5 said array elements are stored contiguously starting at the base address. That is not trivia — it is the mechanism. For int a[5] whose base address is 1004:

what a[i] compiles to
&a[i]  =  base + i × sizeof(int)
&a[0]  =  1004 + 0 × 4  =  1004      ; ← why indices start at ZERO:
&a[3]  =  1004 + 3 × 4  =  1016      ;   the first element is 0 steps away

One multiply, one add — the same cost for a[0] and a[4999]. For a double array the ×4 becomes ×8; the formula never changes.

S6.22-D arrays: the grid is a lie

int b[3][4] is not a grid in memory — it is 12 consecutive cells with one more layer of the same arithmetic, called row-major order:

b[r][c] flattened
flat position  =  r × COLS + c
&b[r][c]       =  base + (r × 4 + c) × sizeof(int)

; b[1][2] → 1 × 4 + 2 = flat #6 — the 7th cell of the block

This is why the inner loop of Chapter 5's nested walks runs over columns: consecutive c values are physically adjacent in memory.

S6.3The formula has no idea where the array ends

Here is the dark side: base + i × 4 computes an address for any i. Real C++ performs no bounds check — a[5] on a 5-element array simply computes the next address after the array and writes there, destroying whichever variable happens to live at it. No error, no warning; the corruption surfaces later, somewhere else. This bug class — buffer overflow — has powered decades of security exploits.

Why does C++ allow this? Speed. A bounds check on every access costs instructions (S5!), and C++'s founding bargain is “you don't pay for what you don't use”. Higher-level languages chose the check; C++ chose to trust you. The playground on the chapter pages adds the check back while you learn.
