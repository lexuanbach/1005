How Text Becomes BytesSupplementary

S4 showed integers in bits, S3 showed doubles — this topic finishes the set: text. A char is just a small number, ASCII maps the English keyboard into 128 of them… and then Vietnamese happens. Unicode gives every character on Earth a number, UTF-8 packs those numbers into bytes — and suddenly “Xin chào” has 8 characters but 9 bytes, which is exactly what a C++ string will count.

01 · The idea

From 'A' to chào: three layers of encoding

S8.1ASCII: 128 numbers for an English keyboard

You already know the secret from Chapters 3 and 5: 'A' is 65, 'a' + 1 == 'b', and a char is an 8-bit integer (S4!). The mapping is ASCII: codes 0–127 cover English letters, digits, punctuation, and control characters like '\n' (code 10). Neat, tiny — and hopelessly insufficient for most of the world's languages.

S8.2Unicode: a number for every character on Earth

Unicode extends the idea to everything: each character gets a code point, written U+hex. A is U+0041 (still 65 — ASCII is Unicode's first 128 rows), à is U+00E0, the Vietnamese ệ is U+1EC7, and 🚀 is U+1F680. Over 150,000 characters have numbers today. A code point is which character — it says nothing yet about bytes.

S8.3UTF-8: packing code points into bytes

UTF-8 is the encoding that turns code points into bytes — using one to four bytes per character, small codes getting fewer bytes:

utf8_sizes.txt
U+0000 … U+007F   → 1 byte    A → 41            (all of ASCII, unchanged!)
U+0080 … U+07FF   → 2 bytes   à → C3 A0
U+0800 … U+FFFF   → 3 bytes   ệ → E1 BB 87
U+10000 and up    → 4 bytes   🚀 → F0 9F 9A 80

The genius move: ASCII text is already valid UTF-8, byte for byte. That backward compatibility is why UTF-8 quietly conquered the web — including this page.

S8.4What this means for your C++ strings

A C++ string counts bytes, not characters. For pure ASCII the two agree — but string s = "Xin chào"; has s.length() == 9, because à occupies two bytes. Indexing s[7] lands you in the middle of à's two bytes, and a char (one byte, S4) simply cannot hold 'à'. The rule of thumb for now: treat non-ASCII strings as whole values — print them, concatenate them — and be careful indexing into them character by character.

Why the slides never hit this Every example in Chapters 1–6 uses ASCII text, where 1 character = 1 byte and nothing surprises you. The moment your programs speak Vietnamese, this topic is the difference between confusion and comprehension.
02 · Mini app

Text Inspector — every character, every byte

Type anything. Each character shows its Unicode code point and its UTF-8 bytes in hex; rows beyond ASCII are tinted. The two counters at the top — characters vs bytes — are the whole lesson in two numbers.

Things to try Compare the à vs a preset byte by byte. Type your own full name with diacritics and predict the byte count before looking. Inspect 🚀 — four bytes for one character. Then go to the Playground, run string s = "Xin chào"; cout << s.length(); and watch C++ agree with the byte counter.
