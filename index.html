01 · Course objectives

One semester, two learning paths

This course introduces computing through two main parts: building a foundation in programming with C++, then expanding into the core topics of computer science.

Part 1 · Weeks 35–41

Programming thinking & C++ fundamentals

An introduction to programming thinking and the core concepts of C++ — the foundation for reading, understanding, and writing programs.

  • Variables & data types
  • Conditionals
  • Loops
  • Functions
  • Value vs Reference
Part 2 · Weeks 43–50

Foundations of computer science

A broad view of modern computing systems — from hardware to artificial intelligence, together with academic citation skills.

  • Computer architecture
  • Assembly
  • Compiler
  • Computer networks
  • Databases
  • AI & LLM
  • Information security
  • Academic citation
02 · Expected learning outcomes

By the end of the course, students can

C++ programming

  • Understand and write basic C++ programs
  • Use variables, data types, conditionals, loops, and functions
  • Distinguish pass by value from pass by reference

Computing foundations

  • Describe, at an introductory level, how computers operate under the Von Neumann architecture
  • Understand the roles of assembly, compilers, networks, and databases in computing systems
  • Understand the roles of AI, LLMs, and security in modern computing

Academic skills

  • Write basic citations correctly
  • Complete assignments according to academic standards

From Source Code to Running Program

How a C++ program is compiled and run, step by step — preprocessor, compiler, assembler, linker — and how the Playground's interpreter takes a different route entirely.

supplementary topic · 8 MCQs S2 · supplementary

From Expression to Computation Tree

Why 8 + 5 * 7 % 2 * 4 is 12: precedence as a tree shape, how the compiler evaluates it bottom-up — with the Tree Lab mini-app that turns any expression into a tree you can step through.

supplementary topic · Tree Lab · 8 MCQs S3 · supplementary

Inside Floating Point

How IEEE 754 stores real numbers, and why 0.1 + 0.2 ≠ 0.3 — traced digit by digit — with the IEEE 754 Lab that turns any number into clickable bits and back.

supplementary topic · IEEE 754 Lab · 8 MCQs S4 · supplementary

Inside Integers

Two's complement: why −1 is all ones, why 127 + 1 wraps to −128, and why the same adder handles negatives — with a lab of clickable bits, ±1 overflow walking, and step-by-step negation.

supplementary topic · Two's Complement Lab · 8 MCQs S5 · supplementary

Loops Are Just Jumps

There is no while instruction in a CPU — every loop is compare-and-jump. The Jump Machine runs your Chapter 4 loops instruction by instruction, program counter and all.

supplementary topic · Jump Machine · 8 MCQs S6 · supplementary

Arrays in Memory

a[i] is one multiply and one add: base + i × size. The Memory Lab shows the address arithmetic live — then lets you write out of bounds and watch a neighbour variable die.

supplementary topic · Memory Lab · 8 MCQs S7 · supplementary

The Call Stack

Calls push frames, returns pop them — one picture that explains auto vs static, scope, references, and recursion. Step through Chapter 6's own examples with the frames drawn live.

supplementary topic · Stack Visualizer · 8 MCQs S8 · supplementary

How Text Becomes Bytes

ASCII, Unicode, UTF-8 — and why "Xin chào" has 8 characters but 9 bytes. The Text Inspector turns anything you type into code points and bytes, tiếng Việt included.
