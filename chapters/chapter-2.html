01 · Learn the concepts

The building blocks of every program

2.1A simple program, line by line

hello.cpp
#include <iostream>   // header file: gives the program I/O capabilities
using namespace std;  // tells the compiler where to find cout, cin, endl

int main()            // the function header line — the entry point
{
    cout << "Hello world!";
    return 0;         // 0 = the program terminated successfully
}
  • Header files notify the compiler that the program uses run-time libraries; the preprocessor (which runs before the compiler) pastes the entire contents of the included file into yours.
  • main() runs automatically when the program executes. Every C++ program must include exactly one — all other functions are executed from it.
  • Its header line tells you three things: what type it returns (int), its name, and what data it receives (here: nothing).
  • All statements in C++ must end with a semicolon.

2.2cout, endl, and comments

The cout object sends data to the standard output display device. The insertion operator << pushes items into the stream, and you can chain it: cout << "Hello " << "C++";. The endl i/o manipulator represents a new line.

Comments are for humans: // a line comment runs to the end of the line; /* a block comment */ can span several lines. The compiler ignores both.

2.3The basic data types

A data type is the category of information a variable contains. The three basic ones: integers (no decimal places: −259, 0, 200), floating point numbers (decimals or exponential notation: −6.16, 2.7541, 90.1e3 = 90.1 × 10³), and characters (char cLetter = 'A'; — single quotes).

Floating point values are stored in the IEEE 754 standard, which splits the bits into a sign, an exponent (the scale), and a mantissa (the fraction):

1exponent · 8mantissa · 23
float — single precision, 32 bits (4 bytes)
1exponent · 11mantissa · 52
double — double precision, 64 bits (8 bytes)
Floating point is approximate A result like 0.1 + 0.2 is not guaranteed to be exactly 0.3. Avoid relying on exact equality (==) between floating-point calculations. Want the full story, bit by bit? See supplementary topic S3 — Inside floating point, which includes a lab that turns any number into its IEEE 754 bits. Integers have a bit story of their own — negative numbers and overflow live in S4 — Inside integers.

Useful escape sequences for characters and strings: \n moves to the next line, \t moves to the next tab stop.

2.4Arithmetic operators — and two traps

OperatorDescriptionExample
+add two operands3 + 7 → 10
-subtract one operand from another18 - 3 → 15
*multiply12.6 * 2.0 → 25.2
/divide15.0 / 2.0 → 7.5
%remainder of an integer division17 % 3 → 2
Trap 1 · integer division The division of two integers yields an integer result: 15 / 2 is 7, not 7.5. Write 15.0 / 2 (or use double variables) to keep the fraction.
Trap 2 · precedence * / % are evaluated before + -, left to right. So 8 + 5 * 7 % 2 * 4 is 8 + ((5×7 % 2) × 4) = 8 + (1 × 4) = 12. Unary minus binds tighter still, right to left.
See it as a tree Want to see why that expression is 12? Supplementary topic S2 — Expression trees turns any expression into its computation tree and lets you evaluate it one operator at a time.

2.5Variables and identifiers

Programming is largely storing and manipulating values in variables. A name (identifier) must begin with a letter or underscore, may contain digits (never first), never special characters like $ & * %, and cannot be a reserved word.

IdentifierVerdictWhy
myVariablevalidcamelCase — the suggested style for C++ in this course
my_variablevalidsnake_case (Python style) — also legal
x1, _my_variablevaliddigits allowed after the first character; leading underscore allowed
%x1invalidstarts with a special character
X$2invalid$ is not allowed anywhere

Declare with <type> <name>; — e.g. int count; or with an initial value, int num = 15;. Two rules: a variable must be declared before it is used, and note that a declaration gives information to the compiler — it is not a step of the algorithm.

2.6Assignment — and the ++ / −− shortcuts

<variable> = <expression>; evaluates the right side first, then stores the result into the variable on the left. The = here is not the equals sign of mathematics — each new value stored simply overwrites the old one. Conversion happens across the operator: if temp is an int, then temp = 25.89; stores 25.

Compound shortcuts: sum += 10 ≡ sum = sum + 10, and likewise -= *= /= %=. For ±1 there are unary operators — and prefix vs postfix matters:

example_2_4_2.cpp
int c = 5;
cout << c++ << endl;  // prints 5 — print first, THEN increment
cout << c << endl;    // prints 6

c = 5;
cout << ++c << endl;  // prints 6 — increment FIRST, then print
cout << c << endl;    // prints 6

2.7Input with the cin object

cin reads from the keyboard via the standard input stream, using the extraction operator >>. When cin >> num1; is reached, the program stops and waits; the typed value is stored into the variable. One statement can read several values:

average3.cpp
int num1, num2, num3;
float average;

cout << "Enter three integer numbers: ";
cin >> num1 >> num2 >> num3;
average = (num1 + num2 + num3) / 3.0;   // 3.0, not 3 — why?
cout << "The average of the numbers is " << average << endl;

2.8Mathematical library functions

Add #include <cmath> (the modern C++ math header) and you can call:

FunctionDescriptionReturns
sqrt(a)square root of adouble
pow(a1, a2)a1 raised to the power a2double
abs(a)absolute valuesame type as the argument
log(a) · log10(a)natural log · base-10 logdouble
sin(a) · cos(a) · tan(a)trigonometry (a in radians)double
exp(a)ea, where e ≈ 2.71828double

Except abs, all take a double argument and return a double.

2.9Formatting the output

A program should present results attractively. Stream manipulators from #include <iomanip> control the format: setw(n) sets the minimum field width for the next item only (right-aligned), and setprecision(n) controls digits — with the fixed flag enabled, that means n digits after the decimal point.

example_2_7_1.cpp
cout << "|" << setw(10)
     << setprecision(3) << fixed << 25.67 << "|";

// prints:   |    25.670|
// to reset the fixed behaviour afterwards, use defaultfloat

04 · Team activity

Group discussion: pitch a tiny console program

Teams of 3–4 · one class period to prepare · a 5-minute demo-and-pitch. Counts toward the class-activities 10%.

The task

Design and build a small console tool that a first-year student would actually use — a tuition-and-costs estimator, a unit converter, a GPA calculator, a currency splitter. The team writes a one-page spec (inputs, formulas, exact output format), then implements it in the Playground and demos it live.

Constraints that force Chapter 2 thinking

  • At least one place where integer division vs real division matters — and the team must explain their choice of types.
  • Formatted output with setw / setprecision / fixed — money must show exactly 2 decimals, columns must line up.
  • Every variable name follows the identifier rules and camelCase style.

Roles

RoleResponsibility
Product ownerwrites the spec and defends every input/output decision
Programmertypes the code live during the demo (the whole team designs it)
Type inspectorjustifies every data type; hunts down the integer-division trap
Presenterruns the pitch: problem → demo → one thing that went wrong
Discussion starters Why double and not float? What happens to your program when the user types a word instead of a number? Why is average = sum / 3 a bug when sum is an int — and how did your team catch it?
